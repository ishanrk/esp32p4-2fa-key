USB ROUTING

The Type-C connector labeled USB is wired to ESP32-P4 full-speed PHY0. At
reset that PHY is assigned to USB Serial/JTAG. Before TinyUSB starts, the board
helper uses the supported ESP-IDF USB wrapper selector to route OTG1.1 to PHY0.
This is a reversible software selection and does not write an eFuse.

The separate Type-C connector labeled PWR USB TO UART terminates at the CH343P
and is used for flashing and logs. It is not the native FIDO device path. The
Type-A high-speed OTG connector bank is not used by this firmware.

BUTTON

BOOT connects GPIO35 to ground. Firmware enables the internal pull-up, requires
a stable release before each request, debounces a fresh active-low press, and
uses that press for FIDO user presence.

TESTED BASELINE

The normal firmware has been built with ESP-IDF v6.0.2 for the pre-v3 silicon
path and run on revision v1.3. Runtime checks reported two cores, 16 MiB flash,
32 MiB PSRAM, UART logging on GPIO37/GPIO38, and native FIDO HID enumeration on
the Type-C USB connector.

POWER

The USB and PWR USB TO UART inputs join the board 5 V network through the board
power-selection circuit. Do not add an unrelated external 5 V source while the
board is USB powered.
