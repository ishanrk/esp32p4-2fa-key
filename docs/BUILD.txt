ESP32-P4 2FA KEY BUILD

REQUIREMENTS

ESP-IDF v6.0.2 with the ESP32-P4 toolchain
Python 3
CMake and Ninja from the ESP-IDF environment

The managed USB component versions are pinned by main/idf_component.yml and
dependencies.lock. Host-only FIDO and HID packages are pinned in
requirements-host.txt.

ENVIRONMENT

From the repository root:

. /path/to/esp-idf/export.sh
python3 scripts/env_check.py

The environment checker reports missing tools or a different ESP-IDF version.
It does not install or modify software.

NORMAL BUILD

scripts/build.sh

The script selects esp32p4 when needed, then runs idf.py build and idf.py size.
The tracked sdkconfig.defaults is the reproducible normal configuration. The
generated sdkconfig and build directory remain local.

HOST TESTS

python3 -m unittest discover -s tests/host -v

The host suite compiles the bounded C helpers and protocol paths with strict
warnings and checks CBOR, CTAP2, CTAPHID, wrapped credentials, user presence,
USB descriptors, and the normal hardware-crypto configuration.

FLASH

Connect the Type-C port labeled PWR USB TO UART, then run:

scripts/flash.sh PORT

or:

P4KEY_PORT=PORT scripts/flash.sh

The wrapper performs a normal idf.py flash. It does not request a whole-flash
erase. UART logs are available with scripts/monitor.sh PORT.

NORMAL USB USE

After flashing, connect the separate Type-C port labeled USB to the host. That
connector carries the native FIDO HID device. PWR USB TO UART is only the
flashing and logging path.

CONFIGURATION

sdkconfig.defaults selects the attached pre-v3 ESP32-P4 path, 16 MiB flash,
PSRAM, one full-speed HID interface, hardware SHA, hardware AES/GCM, and the
general P-256 ECC accelerator. Secure Boot and flash encryption remain off.
