ENVIRONMENT

From the repository root:

. /home/ishan/esp-idf/export.sh
python3 scripts/env_check.py

The environment checker reports every required host tool and never installs
or changes software. A wrong IDF version fails unless the developer passes
--allow-version-mismatch explicitly.

BUILD

scripts/build.sh

The script selects esp32p4 only when sdkconfig is absent or targets something
else. It then runs:

idf.py build
idf.py size

The source controlled sdkconfig.defaults enables the proven 16 MB flash,
the module PSRAM, development logging on UART0, and no irreversible security
feature. The generated sdkconfig remains local.

FLASH

scripts/flash.sh PORT

or:

P4KEY_PORT=PORT scripts/flash.sh

The wrapper runs idf.py -p PORT flash. It does not erase the whole flash and
does not start a monitor.

MONITOR

scripts/monitor.sh PORT

or:

P4KEY_PORT=PORT scripts/monitor.sh

The board's logging connector is the Type-C port labeled PWR USB TO UART.
It uses a CH343P and appeared on the current Windows host as COM7.
This WSL environment cannot currently open that Windows serial device.

The native FIDO device candidate is the separate Type-C connector labeled USB.
Do not put FIDO traffic on the CH343 logging connector.

HOST TESTS

python3 -m unittest discover -s tests/host -v

The suite compiles the pure button helper with -Wall -Wextra -Werror and checks
active low active high and unconfigured GPIO behavior. It also runs state_check
against filled missing-file and likely-secret fixtures.
