P4KEY DEVELOPMENT USB ID NOTICE

The Prompt 03 development firmware uses USB VID 0x303A and PID 0x4004.

esp_tinyusb explicitly permits the Espressif VID during product development.
Its documented interface bitmap gives PID 0x4004 for an HID-only device.
These values are used only to establish the local one-interface USB baseline.

They are not a product identity and must not be used for shipment. Obtain an
assigned VID and PID or an authorized sublicense before distributing hardware.
Do not substitute a commercial authenticator vendor's identity.

The device descriptor has no USB serial string. Firmware must not derive one
from a MAC address, chip ID, eFuse value, credential, or other device secret.
